# どうせやらないタスク管理

やる気ゼロでも、皮肉でお祝いされる。登録するだけで満足できる、皮肉たっぷりのタスク管理です。

https://kamomutsu09-spec.github.io/sarcastic-todo/

## 特徴

- **完了ガチャ**: タスクを完了すると、皮肉なお祝いが N / R / SR / SSR で出ます。
- **言い訳ガチャ**: 押せない日は「言い訳」を選べます。
- **図鑑・実績**: お祝い図鑑、言い訳図鑑、実績をコンプリートしましょう。
- **締切・放置日数いじり**: 遅れた日数に応じて、皮肉が強くなります。
- **通知**: 締切・放置日数・毎日の一言を、ブラウザの通知でお知らせします(ページを開いている間だけ)。
- **𝕏 でシェア**: 現在の成績や、ガチャの結果を投稿できます。ハッシュタグは **#皮肉タスク** です。
- **バックアップ**: 記録をファイルに書き出して、別のブラウザや端末で読み込めます。

## データの保存について

記録は、**お使いのブラウザの中(localStorage)にだけ**保存されます。サーバーには送られません。
ブラウザの閲覧データの削除、プライベートウィンドウの利用、別のブラウザや端末での利用などで、**簡単に消えることがあります**。
大切な記録は、画面下の「データのバックアップ」から、ファイルに書き出しておいてください。

## 技術

`index.html` 1ファイルだけで動きます(HTML / CSS / JavaScript、外部ライブラリなし)。
